A structured collection of laboratory experiments, hands-on tasks, and coursework assignments completed for the **Web Programming** course at **Riphah International University**.

---

## 📂 Laboratory Contents

- **`Lab Task 1` - `Lab Task 5`**:
  - Semantic HTML layout structures and accessible element hierarchy.
  - CSS styling techniques: Flexbox, Grid, positioning, and responsive media queries.
  - Image optimization and media asset management.
- **`Assignment 1`**:
  - Multimedia integration: embedding audio (`audioo.mp3`), video players, and custom styling.
- **`Assignment 2`**:
  - Interactive social feed prototype (`feed.html`, `feed.css`, `script.js`).
  - Client-side DOM event handling, user interaction, and layout scripting.

---

## 🚀 Running Locally

All tasks are client-side. Open any file directly in a web browser:

```bash
# Example: Run Assignment 2
cd "Assignment2"
xdg-open index.html
```
